Anywhere else

Songs

Songs that show up properly in your music app

From YouTube Music, Spotify and Apple Music, every song is saved as an MP3 or M4A with its title, artist, album and cover art written into the file.

  • MP3 plays everywhere; M4A keeps the audio exactly as it’s streamed, with no conversion
  • Spotify and Apple Music audio is copy-protected, so it’s never touched: the same recording is found on YouTube Music and saved from there
  • Point at MP3 or M4A in the menu to see which recording was found
  • Cover art and 30-second previews come straight from the source

Toolbar

Got a link? Paste it.

Click the Just download it button in your browser’s toolbar and paste any link. It looks it up as soon as you paste, and lists everything you can save.

  • Works with links from any of the supported sites, or a direct link to a file
  • Download from this tab uses the page you’re on
  • Save the page as an Image (PNG) or a GIF from here too
  • Progress shows on the toolbar icon, so you can close the popup and carry on

Private

It all happens on your computer

There is no Just download it server. Your browser does the work, and your files never go anywhere but your Downloads folder.

  • No server

    Video and sound are joined, MP3s encoded and GIFs recorded by your own browser.

  • No account, no ads

    No sign-up, no paid tier, no analytics. It’s free.

  • Only the site you’re on

    It talks to the site you’re downloading from, and to YouTube Music and Apple’s iTunes search when it’s finding a song and its tags. Nothing else.

  • No remote code

    Everything it runs ships inside the extension. Nothing is fetched and run later.

How it works

Three steps, and no surprises

  1. 1

    Click Download

    Use the button on the site, right-click, or paste a link into the toolbar popup.

  2. 2

    Pick a quality

    The menu lists every version the site has. The best is already selected. Arrow keys move, Enter saves, Esc closes.

  3. 3

    It lands in Downloads

    Through your browser’s normal downloads. Big jobs show a progress bubble in the corner of the page.

What happens on your computer

Plain files go straight to your browser’s downloads. When a file needs work, such as joining a 4K video’s separate picture and sound, making an MP3, writing tags or recording a GIF, a hidden page inside the extension does it with the open-source Mediabunny library, then hands the finished file to the browser. Long 4K videos, Twitch broadcasts and long playlists can take a while.

Spotify and Apple Music

Their audio is DRM-protected, and the extension never touches it. It reads the song’s title, artist, album and length from their public pages, finds the same recording on YouTube Music, and saves that with the tags and cover art written in. Check the match shown in the menu: now and then it picks a different version.

YouTube

No cookies and no account are used. The extension asks YouTube’s player for a video’s streams the way a YouTube app does. YouTube changes what works every few months, so now and then it needs an update. Age-restricted, private and members-only videos aren’t supported.

Instagram

It asks Instagram for a post only when you click, one request at a time, using the account you’re already logged in with. If Instagram says to slow down, it waits and offers the version shown on the page instead. It’s built for saving things one at a time, not for bulk scraping.

Open on GitHub

Chrome

  1. Open the extensions page

    Type this into Chrome’s address bar:

    chrome://extensions

  2. Turn on Developer mode

    It’s the switch in the top-right corner. Leave it on: Chrome turns off extensions loaded this way when it’s off.

  3. Click Load unpacked

    Pick the extension folder inside the project, the one with manifest.json in it, not the project folder itself.

To update, replace the files with the new version, then click the reload icon on the extension’s card.

Firefox

  1. Build the Firefox version

    With Node.js 20 or newer, run npm install and then npm run build:firefox in the project folder. It lands in dist/firefox/.

  2. Open the debugging page

    Type this into Firefox’s address bar:

    about:debugging#/runtime/this-firefox

  3. Click Load Temporary Add-on…

    Pick dist/firefox/manifest.json. If Firefox asks, let it access all websites: it needs that to add its buttons and fetch the files.

Firefox removes temporary add-ons when it restarts, so this is for trying it out. Firefox 140 or newer.

FAQ

Questions

Is it really free?

Yes. There’s no paid tier, no account, no ads and no trial. It costs nothing to run because there’s no server: your browser does all the work.

Is it safe? Does it collect my data?

It collects nothing. There’s no analytics, no account and no remote code, and nothing you download is sent to any server. Requests go only to the site you’re downloading from, plus YouTube Music and Apple’s iTunes search when it’s matching a song and filling in its tags. The privacy policy has the details.

It asks your browser for access to all sites so the Download button and the right-click menu work wherever you are, and so it can fetch the file from the site’s servers. What you browse stays on your computer.

Is it open source?

Yes. All of it is on GitHub under the MIT license, so you can read exactly what it does, build it yourself, or suggest a fix.

The code is plain JavaScript, HTML and CSS, not minified. The two bundled libraries, for video and GIFs, can be rebuilt from their sources with one command.

Why do Spotify and Apple Music songs come from YouTube Music?

Spotify and Apple Music protect their audio with DRM, and the extension never touches it. It reads the song’s title, artist, album and length from their public pages, finds the same recording on YouTube Music, and saves that as an MP3 or M4A with the tags and cover art filled in.

The menu shows which recording it found. Now and then it can pick a different version, like a live take, so it’s worth a glance.

Where do my files go?

Into your normal Downloads folder, in a Just Download It folder with a subfolder for each site. For example:

Downloads/Just Download It/YouTube/Me at the zoo [jNQXAC9IVRw] 1080p.mp4

You can rename the folder, turn off the per-site subfolders, or have your browser ask where to save every file, in the settings.

How do I update it?

You don’t need to. Installed from the Chrome Web Store or Firefox Add-ons, it updates by itself, and your settings stay.

If you installed it from source, replace the files with the new version from GitHub, then click the reload icon on its card in chrome://extensions. In Firefox, build it again and click Reload in about:debugging.

Is there anything it can’t download?

Age-restricted, private and members-only YouTube videos aren’t supported, and copy-protected (DRM) audio and video is never touched. Sites also change how they work from time to time, so a button can stop working until the extension is updated.
